# hxyfront-62009 地毯修复纹样档案 · 续作修订账

源提示词编号：2

给手工地毯修复工作室使用的纹样与修复档案前端：记录地毯产地、年代、结密度、材质、染色类型、
破损区域、补线颜色和修复工序；包含纹样局部标记图、修复前后记录、材料色卡、工序进度、按产地
筛选的档案列表，以及面向「库房断网」场景的**续作修订账**。

## 修订账规则（针对旧版问题）

1. **字段级三向并回，后写不再覆盖**
   - 平板断网补录按 `(地毯编号, 字段)` 与总档合并，破损区域按 `damage:<编号>` 独立成字段。
   - 合并基准为离线时看到的 `base`：总档未改 → 直接并回；同一字段两边都改过 →
     **两版并存（conflict）**，总档保持现值，修复师在修订账里人工选择平板版或总档版。
2. **色卡过期 / 范围调整 → 立即作废重算**
   - 使用该色卡的未完成工序（待开工、进行中）立即作废，其修复前/修复后记录同步作废，
     自动生成「（色卡重算）」后继工序，必须重新指派有效色卡才能开工/完工。
   - 完工操作做硬校验：**色卡失效的工序即使已勾选也不能完工**。
   - 已完工工序不追溯（修复事实保留）；色卡复检合格重新启用不会自动复活旧工序。
3. **断点续传 + 幂等**
   - 断网期间所有操作进入平板待传队列并持久化到 localStorage。
   - 上传在第 N 笔失败时中断：前 N−1 笔全部保留为已入库，恢复后**只补 pending/failed 项**。
   - 每笔操作带 `opId`，服务端维护已处理操作表；**重复提交返回幂等命中，不生成第二份记录**
     （修订账、修复后记录都不会翻倍）。

## 页面与演示路径

- 顶部状态条：`模拟断网 / 恢复联网`、`⚡ 模拟上传失败`（验证断点续传）。
- 左列：按产地筛选的地毯列表（带「离线待并回 / 两版待确认」角标）、材料色卡（复检判过期、
  调整范围、复检合格启用）。
- 右列：纹样局部标记图（点击破损点按编号补录）、字段补录、工序与修复前后记录。
  每个字段旁的「模拟总档并发改」可制造两边都改同字段的冲突场景。
- 底部：续作修订账（两版裁决）、平板待传队列（已入库项可点「重复提交」验证幂等）、流水日志。

推荐演示顺序：断网 → 改 CAR-092 字段并对其中一字段做「模拟总档并发改」→
点「⚡ 模拟上传失败」后恢复联网 → 观察前几笔入库、失败笔待补 → 再次恢复只补未完成项 →
在修订账裁决两版 → 对「茜草红 M3」（今日到期）判过期，观察工序与前后记录作废重算 →
对已入库记录点重复提交，确认无第二份记录。
